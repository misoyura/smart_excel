2-5. [09-①] IF 테스트: 매출액이 맞을까? 실습 3분 · 09 시트 · D6:D15 채우기

학생 빈칸을 채워 AI에게 요청 → AI 수식 작성·설명 → Excel D6~D15 계산

PROMPT · [09-①] IF 테스트 (빈칸 채우기) 
나는 Excel [      ] 버전을 사용해.
「09_함수테스트」에서 수량은 A열, 판매단가는 [   ]열,
매출액은 [   ]열이야.
수량×판매단가가 매출액과 같으면 "[      ]",
다르면 "[        ]"라고 D열에 표시하는
수식을 만들어줘. 수식 설명도 해줘.
  1. D6에 수식 입력
  2. 채우기 핸들 더블클릭
  3. E열 예상 결과와 비교
  4. 검토필요가 3건이면 통과

수식 예시

=IF(A6*B6=C6,"정상","검토필요")
