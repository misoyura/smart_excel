0605에 적용했더니… 함정 발견!

실습 05 시트 · N열 매출검증 채우기

수식 · 05 시트 N2에 입력 후 아래로 채우기 IF
=IF(F2*G2=H2,"정상","검토필요")
행상황결과
33행 "3월 소계"빈칸 × 빈칸 = 빈칸"정상" (틀림!)
39행매출액 '13500' (텍스트) — 계산은 맞는데"검토필요" (틀림!)
⚠️ 테스트는 통과했는데 실전에서 틀렸습니다 테스트 데이터에 없던 상황(빈칸 · 텍스트 숫자)이 실전에는 있기 때문입니다.

AI에게 조건을 추가해 다시 요청

개선 수식 · N열 IF + COUNT
=IF(COUNT(F2:H2)<3,"값확인",IF(F2*G2=H2,"정상","검토필요"))
COUNT는 숫자만 셉니다. F·G·H 중 하나라도 빈칸이거나 텍스트면 → 개수가 3보다 작음 → "값확인"
검토필요 2건41 · 72행
값확인 10건소계·메모 3(33·66·93) + 빈칸 3(8·59·96) + 텍스트 숫자 4(31·39·57·82)

더 자세한 조건으로 요청하기 (생략 가능)

10중복 찾기: 똑같은 행이 있나?

실습 05 시트 · O열(중복키) · P열(중복여부)

한 행을 문자열 하나로 학생 실습

수식 · O2 중복키 TEXTJOIN
=TEXTJOIN("|",FALSE,A2:L2)

FALSE는 빈칸을 무시하지 않음(공백 유지)

수식 · P2 중복여부 IF + COUNTIF
=IF(COUNTIF($O$2:$O$101,O2)>1,"중복","")

O2:P2 함께 선택 → 101행까지 채우기

결과: 중복 2쌍 (4행) — 두 행 모두 "중복" 표시 → 지울 것은 한 행뿐
COUNTIF = "나랑 똑같은 행이 몇 개?"
P열은 찾기만 합니다 — 실제 삭제는 PART 3 「중복된 항목 제거」, 날짜 변환도 PART 3에서 합니다.

11[09-③] SUMIFS 테스트: 오류 없이 틀린 값

실습 4분 09 시트 · M33:M36 / O33:O36

M33~M35에 조건 칸(J~L)을 참조하는 SUMIFS → N열 예상 결과와 비교 → O열에 표를 보고 직접 계산합니다.

수식 · 09 시트 M33 SUMIFS
=SUMIFS($D$33:$D$42,$A$33:$A$42,J33,$B$33:$B$42,K33,$C$33:$C$42,L33)
수식 · 09 시트 M36 (월 조건 빼고 따로 입력) SUMIFS
=SUMIFS($D$33:$D$42,$B$33:$B$42,K36,$C$33:$C$42,L36)
문제SUMIFS 결과직접 계산차이 원인
Q1 3월 신구점 판매14,00021,000"신구 점" 7,000 누락
Q2 4월 성남점 판매9,0009,000일치 (취소 3,000은 정상 제외)
Q3 5월 용인점 판매12,00017,000"용인 점" 5,000 누락
Q4 신구점 판매 전체14,00029,000"신구 점" + 텍스트 "8,000" 누락
⚠️ Q2만 맞습니다 수식이 아니라 데이터가 틀린 것. SUMIFS는 오류 없이 조용히 틀립니다.

Q4 계산 시 M33을 복사하면 0, 월 조건을 빼면 14,000이 나옵니다.
