01분석 준비: 표로 변환

실습 05 시트 · 3행 삭제 → 표(Ctrl+T)

  1. 확인필요 3행 처리 (삭제 또는 표시)마지막 행 93 (데이터 92행) 확인
  2. 데이터 안 아무 셀 클릭
  3. Ctrl+T → "머리글 포함" 체크 → 확인

왜 표로 만들까요?

  • 데이터가 늘어나도 피벗 범위가 자동으로 확장됩니다.
  • 필터·서식이 자동 적용됩니다.

확인하기

  • '표 디자인' 탭이 나타나면 성공
  • 표 이름을 "매출"로 바꿔 두면 편리
  • 표 범위가 A1:P93 (W열은 포함되지 않아야 함)
정리된 데이터 + 표 구조 = 분석할 준비 완료
🧾 피벗을 쓰는 이유? 영수증 92장을 바닥에 펼쳐놓고, 지점별로 줄 세우고, 월별로 칸을 나눠서, 금액을 더하는 일은 Excel이 1초만에 해줍니다.
행: 줄 세울 기준 · 열: 칸 나눌 기준 · 값: 더할 숫자 · 필터: 빼고 볼 것

03피벗테이블 만들기

실습 06 시트 · A3에 피벗

피벗 필드 배치

필터

주문상태 = 판매

열

주문일자 (월)

행

지점명

값

합계 : 매출액

만드는 순서

  1. 표 안 클릭 → 삽입 → 피벗 테이블표/범위: 매출
  2. 기존 워크시트 → 06_피벗분석 A3
  3. 필드 배치필터=주문상태(판매만) / 열=주문일자 / 행=지점명 / 값=합계: 매출액
  4. 날짜가 일 단위로 펼쳐지면날짜 셀 우클릭 → 그룹 → "월"만 선택(일 해제) → 확인
  5. 값 서식 지정값 우클릭 → 값 필드 설정 → 표시 형식 → 숫자, 1000 단위 구분
월 그룹이 안 된다면? 텍스트 날짜가 남아 있다는 신호입니다 — "피벗이 검사관 역할"
"그룹으로 묶을 수 없습니다" 메시지 → 텍스트 날짜가 남은 것 → 05 A열 확인 후 새로 고침 (Alt+F5)
