04정제 ①: 불필요한 행 → 중복 제거

실습 05 시트 · 행 삭제 → 중복 제거

순서가 중요합니다 — 소계·메모 행을 먼저 지우고 중복을 제거합니다.

1. 불필요한 행 삭제

  1. L열 비고 열 필터 → "분석 제외"
  2. 보이는 3행(33·66·93) 선택 → 행 삭제
  3. 필터 해제
결과: 3행 삭제

2. 중복 제거

  1. 데이터 안 "셀 하나만" 클릭
  2. 데이터 탭 → 중복된 항목 제거'머리글 표시' 체크
  3. A~L열만 체크 (도우미 열 제외)
  4. 확인 메시지 확인
결과: 2개 제거
112,600원중복 제거 후 W2 (3월 신구점 판매)
⚠️ 주의도우미 열(M~P)까지 체크하면 중복 판정이 달라질 수 있습니다.

06정제 ③: 명칭 · 코드 표준화 + 매출액 재계산

실습 05 시트 · R~U → C·D·E·H열 교체

원칙: 빈 열(R~U)에서 수식으로 만들기 → 값으로 붙여넣기 → 원래 열 교체. 사람이 쓴 이름보다 코드를 믿습니다.

순서

  1. 지점명 (R열 → C열)
  2. 상품코드 (S열 → D열)
  3. 상품명 (T열 → E열)반드시 ② 다음에
  4. 판매단가 빈칸 채우기
  5. 매출액 재계산 (U열 → H열)
  6. 정리

③-1 지점명 바로잡기 (R열 → C열)

  1. R2에 수식 입력
  2. 더블클릭으로 R96까지 채우기
  3. R열 복사 → C2에 값 붙여넣기
수식 · R2 지점명 XLOOKUP
=XLOOKUP(B2,'04_지점Master'!$A$2:$A$4,'04_지점Master'!$B$2:$B$4,"확인필요")
쉽게 말하면이 행의 지점코드(B2)로 지점Master에서 표준 지점명을 찾아 옵니다 — "학번으로 이름 찾기"
✅ 확인C열 필터 → 신구점 · 성남점 · 용인점 3개만 남으면 성공 · W2 = 140,100원
⚠️ 주의수식 속 A열은 '04_지점Master'의 지점코드 열입니다 (05 시트의 주문일자 아님)
140,100원지점명 정리 후 W2

③-2 상품코드 되살리기 (S열 → D열)

  1. S2에 수식 입력
  2. 더블클릭으로 S96까지 채우기
  3. S열 복사 → D2에 값 붙여넣기
수식 · S2 상품코드 IF · COUNTIF · XLOOKUP · SUBSTITUTE
=IF(COUNTIF('03_상품Master'!$A$2:$A$11,D2)>0,D2,
XLOOKUP(SUBSTITUTE(E2," ",""),'03_상품Master'!$B$2:$B$11,'03_상품Master'!$A$2:$A$11,"확인필요"))
쉽게 말하면코드가 Master에 있으면 그대로 / 없으면(P013 · 빈칸) 상품명 공백을 빼고 코드를 거꾸로 찾습니다.
✅ 확인M열(상품분류)의 "확인필요"가 모두 사라지면 성공 (05 시트 49 · 61 · 93행)

③-3 상품명 통일하기 (T열 → E열)

  1. T2에 수식 입력
  2. 더블클릭으로 T96까지 채우기
  3. T열 복사 → E2에 값 붙여넣기
수식 · T2 상품명 XLOOKUP
=XLOOKUP(D2,'03_상품Master'!$A$2:$A$11,'03_상품Master'!$B$2:$B$11,"확인필요")
쉽게 말하면방금 고친 상품코드로 Master에서 정확한 상품명을 가져옵니다.
✅ 확인E열 필터 → "카페 라떼" · "아메리카노 " 같은 띄어쓰기 표기와 빈칸이 사라지면 성공
⚠️ 주의반드시 ② 상품코드 다음에! 먼저 하면 P013 행이 "확인필요"가 되어 되살릴 단서가 사라집니다.

③-4 판매단가 빈칸 채우기

  1. G열 필터 ▼ → "(필드 값 없음)"만 선택
  2. 4500 입력
  3. 필터 해제
대상05 시트 91행 · 바닐라라떼(P003) → 4,500원
쉽게 말하면비어 있는 가격은 기준표(03_상품Master)의 정상판매가로 채웁니다.
✅ 확인G열 필터 목록에 "(필드 값 없음)"이 사라지면 성공

③-5 매출액 다시 계산하기 (U열 → H열)

  1. U2에 수식 입력
  2. 더블클릭으로 U96까지 채우기
  3. U열 복사 → H2에 값 붙여넣기
수식 · U2 매출액 재계산 IF + COUNT
=IF(COUNT(F2:G2)<2,H2,F2*G2)
쉽게 말하면수량 · 단가가 둘 다 숫자면 다시 곱하고, 하나라도 비어 있으면 원래 매출액을 그대로 둡니다.
✅ 확인W2 = 140,600원 · N열 "검토필요" 0건
⚠️ 주의U열만 만들면 아무것도 바뀌지 않습니다 → 반드시 H2에 "값으로 붙여넣기"까지!
140,600원매출액 재계산 후 W2

③-6 임시 열 정리 + 결과 확인

  1. R~U열 머리글 선택
  2. Delete 키 (내용만 지우기)
  3. 열 삭제는 하지 않기
쉽게 말하면빈 열에서 수식 → 값으로 붙여넣기 → 원래 열 교체. 사람이 쓴 이름보다 코드를 믿습니다.
✅ 확인W2가 140,600원이면 정제 ③ 완료 · R~U열이 비어 있고 W2는 그대로 · 정제 전 130,600원 → 정제 후 140,600원
⚠️ 주의R~U "열 삭제"를 하면 W열이 왼쪽으로 밀립니다 → Delete 키로 내용만 지우세요.

07조건부 서식으로 남은 문제 강조

실습 05 시트 · A2:L96 조건부 서식

이렇게 설정하세요

  1. A2:L96 범위 선택
  2. 홈 → 조건부 서식 → 새 규칙
  3. "수식을 사용하여 서식을 지정할 셀 결정"
  4. 수식 입력 → 서식 → 연한 빨강 채우기
조건부 서식 수식 OR · NOT · ISNUMBER
=OR($N2<>"정상",NOT(ISNUMBER($A2)),$K2="")
N열이 정상이 아니거나, 또는 날짜가 숫자가 아니거나, 또는 주문상태가 빈칸이면 칠합니다. 열 문자 앞에만 $ → 행 전체가 칠해집니다.
