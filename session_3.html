04정제 ①: 불필요한 행 → 중복 제거

실습 05 시트 · 행 삭제 → 중복 제거

순서가 중요합니다 — 소계·메모 행을 먼저 지우고 중복을 제거합니다.

1. 불필요한 행 삭제

  1. L열 비고 열 필터 → "분석 제외"
  2. 보이는 3행(33·66·93) 선택 → 행 삭제
  3. 필터 해제
결과: 3행 삭제

2. 중복 제거

  1. 데이터 안 "셀 하나만" 클릭
  2. 데이터 탭 → 중복된 항목 제거'머리글 표시' 체크
  3. A~L열만 체크 (도우미 열 제외)
  4. 확인 메시지 확인
결과: 2개 제거
112,600원중복 제거 후 W2 (3월 신구점 판매)
⚠️ 주의도우미 열(M~Q)까지 체크하면 중복 판정이 달라질 수 있습니다.

05정제 ②: 숫자 · 날짜 형식 통일

실습 05 시트 · Q열 → A열에 값 붙여넣기

텍스트 숫자

  1. N열 필터 → "값확인"
  2. 셀 왼쪽 위 초록 삼각형 확인
  3. 경고 아이콘(⚠) 클릭 → 숫자로 변환
  4. 필터 해제

텍스트 날짜

05 시트 Q2에 입력 → Q96까지 채우기

수식 · Q2 날짜변환 IFERROR · DATEVALUE · SUBSTITUTE
=IFERROR(IF(ISNUMBER(A2),A2,DATEVALUE(SUBSTITUTE(A2,".","-"))),"확인필요")
"2026.05.03"의 점(.)을 하이픈(-)으로 바꾼 뒤 날짜로 변환합니다.
Excel은 슬래시(/)와 하이픈(-)은 날짜로 알아보는데, 점(.)은 날짜로 인식하지 않습니다.
  1. 결과를 값으로 붙여넣기Ctrl+Alt+V → 값
  2. A열 덮어쓰기
  3. 표시 형식 "날짜"로 지정
136,100원숫자·날짜 변환 후 W2

06정제 ③: 명칭 · 코드 표준화 + 매출액 재계산

실습 05 시트 · R~U → C·D·E·H열 교체

원칙: 사람이 입력한 이름보다 코드를 믿는다 → 명칭은 코드로 Master에서 가져옵니다.
빈 열에서 수식으로 만들기 → 값으로 붙여넣기 → 원래 열 교체

순서

  1. 지점명 (R열 → C열)
  2. 상품코드 (S열 → D열)
  3. 상품명 (T열 → E열)반드시 ② 다음에
  4. 판매단가 빈칸 채우기
  5. 매출액 재계산 (U열 → H열)
  6. 정리

1. 지점명 (R열)

수식 · R2 지점명 XLOOKUP
=XLOOKUP(B2,'04_지점Master'!$A$2:$A$4,'04_지점Master'!$B$2:$B$4,"확인필요")
"이 행의 지점코드(B2)를 Master 코드 목록에서 찾아, 같은 줄의 표준 지점명을 가져와라"
140,100원지점명 정리 후 W2

2. 상품코드 (S열)

수식 · S2 상품코드 IF · COUNTIF · XLOOKUP · SUBSTITUTE
=IF(COUNTIF('03_상품Master'!$A$2:$A$11,D2)>0,D2,
XLOOKUP(SUBSTITUTE(E2," ",""),'03_상품Master'!$B$2:$B$11,'03_상품Master'!$A$2:$A$11,"확인필요"))
"이 코드가 Master에 있나?(COUNTIF>0) 있으면 그대로, 없으면(P013/빈칸) 상품명에서 공백을 빼고, 그 이름으로 코드를 거꾸로 찾아라"

3. 상품명 (T열) — 반드시 ② 다음에

수식 · T2 상품명 XLOOKUP
=XLOOKUP(D2,'03_상품Master'!$A$2:$A$11,'03_상품Master'!$B$2:$B$11,"확인필요")

4. 판매단가 빈칸 채우기

G열 필터 → "(필드 값 없음)" → 1행(05 91행, 바닐라라떼 P003) → 4500 직접 입력 (Master 정상판매가) → 필터 해제

5. 매출액 재계산 (U열 → H열)

수식 · U2 매출액 재계산 IF + COUNT
=IF(COUNT(F2:G2)<2,H2,F2*G2)
수량이나 단가가 빈칸인 행은 원래 매출액을 그대로 두고, 나머지만 재계산합니다.
"모르는 값은 0으로 만들지 말고, 원래 값을 두고 표시만 한다"
140,600원매출액 재계산 후 W2

R~U열 선택 → Delete 키(내용만 지우기). 열 삭제는 하지 않음 (W2 위치 유지)

07조건부 서식으로 남은 문제 강조

실습 05 시트 · A2:L96 조건부 서식

이렇게 설정하세요

  1. A2:L96 범위 선택
  2. 홈 → 조건부 서식 → 새 규칙
  3. "수식을 사용하여 서식을 지정할 셀 결정"
  4. 수식 입력 → 서식 → 연한 빨강 채우기
조건부 서식 수식 OR · NOT · ISNUMBER
=OR($N2<>"정상",NOT(ISNUMBER($A2)),$K2="")
N열이 정상이 아니거나, 또는 날짜가 숫자가 아니거나, 또는 주문상태가 빈칸이면 칠합니다. 열 문자 앞에만 $ → 행 전체가 칠해집니다.
